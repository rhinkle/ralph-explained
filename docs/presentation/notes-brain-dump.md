		2. Customizing the prompt
			1. The prompt you feed into the loop will get called over each time a new iteration starts, so it's important to give enough instructions on what steps you want that instance to do.
			2. A simple version of this could look like
				1. You are an automaton coding agent working on a software project.
				2. Your Tasks are:
					1. Check the task.json file for unfinished tasks.
					2. Check the progress.txt file to understand past changes and share learnings between iterations.
					3. Implement only ONE of the tasks.
					4. Run tests and ensure that tests pass.
					5. If the task is complete, update the task.json
					6. Add changes and learnings to progress.txt file. 
					7. STOP - The next iteration will pick up the next issue.
			3. The Great part about this prompt is that you can change it for your specific use case, if you want to add a step for running static analysis checks. You could easily change this prompt to help research and review an idea to improve the user stories generated by the prd skill.
			4. Since this is looped over, we don't want to add any story details in the prompt; we only want to add the steps we want the loop to run each time.
